# Aosol — إدارة الأصول الثابتة

يضم المستودع تطبيق ويب React وتطبيقًا مكتبيًا مستقلًا ببايثون. النسخة المكتبية واجهتها عربية، وتخزن بياناتها محليًا في SQLite وتعمل دون اتصال بالإنترنت. تُحفظ قاعدة بيانات التطبيق المكتبي منفصلة عن تخزين المتصفح؛ لا توجد مزامنة تلقائية بينهما.

## إمكانات تطبيق Python المكتبي

- إنشاء الأصول وتعديلها وحذفها، مع بيانات الرمز والتصنيف والتواريخ والتكاليف والقيمة التخريدية والعمر الإنتاجي وطريقة الإهلاك والإدارة والموقع والمسؤول والمورد ورقم الفاتورة والرقم التسلسلي والملاحظات.
- دعم القسط الثابت والمتناقص المضاعف 200% والمتناقص 150% ومجموع أرقام السنين ووحدات الإنتاج، مع قواعد بدء الإهلاك، وتقييم الأصول حتى تاريخ محدد.
- سجل أصول يدعم البحث والفلاتر حسب الحالة والتصنيف وطريقة الإهلاك والإدارة، وفرز الأعمدة، وعرض تاريخ التشغيل ومجمع الإهلاك وصافي القيمة الدفترية. يمكن تصدير الأصول الظاهرة بعد الفلترة أو السجل كاملًا.
- تسجيل الاستبعاد بالبيع أو التخريد أو الفقد/التلف أو التبرع، مع التاريخ والمتحصلات والتكاليف والجهة المستلمة والسبب وحساب القيمة الدفترية والربح/الخسارة عند تاريخ العملية.
- مركز تقارير يضم حركة الأصول والإهلاك للفترة، والتجميع حسب التصنيف أو الإدارة، وتقرير الاستبعادات؛ مع فلاتر التاريخ والحالة والتصنيف والإدارة والبحث، ومؤشرات موجزة وتصدير Excel أو CSV.
- تصدير Excel احترافي متعدد الأوراق، عربي من اليمين إلى اليسار، يتضمن سجل الأصول والملخصات وجدول الإهلاك؛ وتقارير الفترة بأوراق مستقلة وملخص تنفيذي ورسم بياني وتنسيق للطباعة على A4 أفقيًا.
- قالب Excel فارغ جاهز للإدخال، ملوّن ومنسق RTL، مع ورقة إرشادات وقوائم منسدلة والتحقق من البيانات. يعرض التطبيق معاينة للصفوف المقبولة والمرفوضة والمكررة وأسبابها قبل الحفظ؛ وتُضاف الدفعة في معاملة SQLite واحدة أو تُلغى كاملةً عند الخطأ.
- استيراد CSV وXLSX وXLSM ونسخ JSON الاحتياطية، وإنشاء نسخة JSON واستعادتها مع اختيار الدمج أو الاستبدال. تحفظ النسخة إعدادات الشركة والعملة والسجل التجاري والرقم الضريبي.
- تمرير رأسي في صفحات التطبيق والنوافذ الطويلة، وتمرير رأسي/أفقي في الجداول، مع إبقاء أزرار الحفظ والتأكيد والإلغاء في أشرطة ثابتة أسفل نوافذ الإدخال.

## التثبيت والتشغيل من المصدر

يتطلب Python 3.10 أو أحدث. على Windows، افتح PowerShell في مجلد المستودع ونفّذ:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

على Linux/macOS ثبّت Tkinter إذا لم يكن متاحًا في توزيعتك، ثم ثبّت المتطلبات وشغّل `python3 main.py`.

## بناء ملف Windows EXE

```powershell
python -m pip install -r requirements.txt
pyinstaller --noconfirm --clean --onefile --windowed --name Aosol --icon assets/aosol.ico main.py
```

يظهر الملف التنفيذي في `dist/Aosol.exe`. كما يبني GitHub Actions الملف تلقائيًا على Windows عند تحديث ملفات Python أو تشغيل سير العمل يدويًا، بعد اجتياز اختبارات Python.

## الاختبارات

```bash
python -m unittest discover -s tests -v
```

تشمل الاختبارات حساب الإهلاك، وحركة التقارير والاستبعادات التاريخية، وإنشاء مصنفات Excel، والتحقق من قالب الاستيراد، والتراجع الذري عند تكرار رمز أصل، واستعادة إعدادات المنشأة.

## مكان تخزين البيانات

- Windows: `%APPDATA%\Aosol\aosol.db`
- Linux: `~/.local/share/aosol/aosol.db`
- macOS: `~/Library/Application Support/Aosol/aosol.db`

احفظ نسخة احتياطية قبل نقل البيانات إلى جهاز آخر أو إعادة تثبيت النظام.

## حدود التكافؤ المعروفة

تحسنت تغطية تطبيق Python، لكنها ليست مطابقة تمامًا لكل مميزات الويب. ما زالت تقارير الأعمدة المخصصة والطباعة/PDF مباشرةً وPWA غير متاحة في النسخة المكتبية. كذلك تُسجل النسخة الحالية إجمالي الوحدات المنتجة للأصل لا حركات الإنتاج المؤرخة؛ لذلك لا يمكن استخراج مصروف إهلاك وحدات الإنتاج لفترة معينة، ويظهر التقرير تنبيهًا بذلك. راجع [مصفوفة مقارنة ميزات الويب وPython](FEATURE_PARITY.md) لقائمة الفروق والتحسينات المقترحة.
